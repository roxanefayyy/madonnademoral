# Madonna Demoral — Procurement Virtual Assistant

Personal landing page. Static HTML, no build step.

## Files
- `index.html` — the page
- `assets/madonna.jpg` — profile photo

## Publish with GitHub Pages
1. Upload both files to the repo root, keeping the `assets/` folder.
2. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. Site goes live at `https://<username>.github.io/<repo-name>/` within a minute or two.
